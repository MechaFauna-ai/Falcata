# Falcata 1.2.0

Unreleased.

## Features and performance

- **Complete bounded device trees by default** (#PR). Quantized single-GPU CUDA trees whose depth bound holds
  (positive `max_depth <= 10` and `2^max_depth <= num_leaves + 1`) now grow entirely on the device: every level's
  select, apply and search plus the final apply, with one growth readback and no host growth tail (`cuda_plan` key
  `device_tree`, now default on). Measured on an RTX 5090 against `device_tree:off` (the 1.1 default flow), same binary:
  covtype deep 1.068x, higgs deep 1.025x, Numerai deep 1.007x, Numerai with missing values 1.002x, four generated
  shapes 1.008-1.042x; geometric mean 1.025x over the eight cells. Model outputs are unchanged (bit-identical models). Other shapes keep
  the `device_levels` prefix and the host flow. Opt out with `cuda_plan="auto,device_tree:off"` (the 1.1 default
  prefix flow) or `cuda_plan="auto,device_levels:off"` (the host flow). The 1.1 opt-in spelling
  `auto,device_levels:off,device_tree:on` now selects the host flow; use `auto` (or `auto,device_tree:on`).
